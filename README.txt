# F90 News Bot (Telegram)

بوت تيليجرام ينشر الأخبار العربية فور صدورها من مصادر متعددة (الجزيرة، العربية، سكاي نيوز، BBC، CNN، RT، قدس، شهاب، معا، رياضة، تقنية، اقتصاد).
- يستخدم صور الخبر إن توفّرت، وإلا يضع شعار F90 News صغير.
- يضيف حقوقك ورابط القناة تلقائيًا في نهاية كل منشور.
- يعمل 24/7 عند تشغيله على Render أو أي خادم Python.

## الإعداد السريع
1) ضع توكن بوتك من BotFather داخل `main.py` مكان النص: `PASTE_YOUR_TELEGRAM_BOT_TOKEN_HERE`
   أو عيّنه كمتغير بيئة `BOT_TOKEN` في Render.
2) لوّن القناة أو المستخدم الهدف في `CHAT_ID` (مثل: `@f90newsnow`).
3) ارفع المشروع إلى GitHub ثم أنشئ Web Service على https://render.com
   - Start Command: `python main.py`
4) سيتم النشر تلقائيًا فور ظهور أخبار جديدة.

## المتطلبات
- Python 3.10+
- feedparser, requests, Pillow (يتم تثبيتها تلقائيًا من requirements.txt)

## تخصيص
- عدّل قائمة المصادر في `SOURCES` كما تشاء.
- لتغيير تكرار الفحص: غيّر `POLL_SECONDS` (الافتراضي 20 ثانية).
- الشعار الاحتياطي موجود في `assets/logo.png` ويمكن استبداله.
